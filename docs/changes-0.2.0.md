# 0.2.0：W830NB 与双设备连接

2026-10-26。新增 W830NB 识别、头戴耳机界面和离线预览。Lolli ANC 与 W830NB 的设置页增加双设备连接开关。用户当前没有 W830NB，其他耳机也不在现场；本次没有连接或写入真实硬件。

## 官方依据

- [W830NB 官方说明书](https://www.edifier.com/cn/instruction/W830NB.html)、[W830NB 官方产品页](https://www.edifier.com/int/uk/p/over-ear-on-ear-headphones/w830nb)：支持双设备连接，需要在 App 中开启。
- [Lolli ANC 官方说明书](https://cn-oss.edifier.com/Uploads/images/2025/07/22/2025072215432017531702001860.pdf)：支持双设备，说明 A、B 设备的配对顺序。
- [官方双设备问答](https://bbs-pc.edifier.com/post/31037)：连接切换、部分设备的编解码和空间音效限制。不能把该页面的说明推广到所有蓝牙产品。
- 本地观察的官方 EDIFIER Connect 8.5.3 安装包与 SHA-256 见 [协议记录](protocol-and-validation.md)。产品表中两条 W830NB 记录分别使用搜索 UUID `00008500-0000-1000-8000-00805f9b34fb` / 服务 `48098501-1a48-11e9-ab14-d663bd873d93`，以及搜索 UUID `00001001-0000-1000-8000-00805f9b34fb` / 服务 `48091001-1a48-11e9-ab14-d663bd873d93`。二者均为头戴式，使用已有公共 RX / TX 和 RFCOMM 服务。产品表不能证明用户手中设备的固件行为。

## 独立实现的协议映射

本地互操作观察位置：`D8Bean.B20Bean`、`CommandManager.getDoubleDevice / setDoubleDevice`、`DoubleDeviceConnectAc`。交付中仅有独立实现和以下协议事实，没有官方源码、安装包或图片。

1. 能力：D8 回复第 20 字节（从零编号）的 bit7。
2. 读取：命令 `7C`，空负载。设置：命令 `7D`。
3. 单字节读取：1 / 3 表示关闭，2 / 4 表示开启。设置统一发送 1（关闭）或 2（开启）。
4. 双字节读取：`[index, state]`，已核对 index 为 0、1、2、3、255，state 为 0 / 1。写入保留原 index；不同格式不能混用。
5. Lolli ANC 修改前要求 F2 返回双耳在线状态 3。未识别的在线形式暂不开放修改。
6. 备份记录双设备状态和类型；恢复时核对类型。双设备设置排在批次最后，其前面的设置仍逐项读回校验。
7. 丢失应答、断线或无法读回均不算成功。界面释放旧管理连接并显示待重连校验；用户再次连接同一耳机时核对目标值。不会自动重发或回滚。该目标在本次应用会话内保留。

W830NB 不套用双金标版的降噪键配置，不显示左右耳、入耳检测或触控页。其能力类型由耳机上报决定。新增 ANC 类型 15、16、17、18、20、22、23 及 EQ 类型 8 的已核对映射，未识别类型仍隐藏；自定义 EQ 仅选择耳机内已有预设，不修改频段。预览使用示例组合，不能证明实际设备返回同一组能力。

## 验证

- 29 项离线测试，包括 117 条原有抓包、两套 W830NB 服务识别、单机电量、不同 ANC 组、双设备两种负载、双耳在线要求、未知格式拒绝、备份前置、恢复、读回不一致与重启断连。
- 7 项真实 WPF 窗口测试，包括三款预览、Lolli ANC / W830NB 双设备开关点击与状态更新，以及关闭窗口回归。
- 单 EXE 独立启动检查在空 .NET 查找路径下执行，生成三款耳机共 21 张界面截图。当前收据见 `portable-build-0.2.0.json`、`portable-check-0.2.0.json`。

默认临时目录启动另遇测试进程创建解压暂存目录失败（错误 5）。已把隔离验证中本 EXE 的五个原生运行库按 SHA-256 核对后放入该版本的专属默认缓存，随后启动和关闭通过；未改变 ACL、注册表或永久环境变量。隔离目录首次解压通过，默认目录首次解压不作通过声明，收据见 `native-startup-check-0.2.0.json`。

这些是软件与模拟响应验证。真实蓝牙连接、固件兼容、双设备音频切换以及重启时序仍待设备到手后验收。
