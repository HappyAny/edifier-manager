# 0.3.0：补齐可独立实现的本地功能

- Lolli ANC 新增 EQ 类型 50 的五档预设，以及触控类型 30 的六个位置、九种动作与降噪循环子选项。
- 增加新版分项提示音、旧版提示音开关、按能力开放的灵敏度、风噪与自动关机。
- 增加改名、定时关机、LDAC、受能力限制且需要确认的设备管理操作。
- 增加自定义 EQ 编辑、逐段读回、默认恢复、导入预览和导出；常规设置备份可恢复自定义 EQ。
- 增加指定耳机端点的限时寻找提示音，以及对应型号官方说明书、官方 App 与功能状态入口。
- 设备身份索引使用地址摘要，改名后仍可识别；备份与诊断不自动上传。

Lolli ANC 1.0.9 已知记录仍未上报独立双设备开关，保留官方配对流程。其触控标志不代表支持调整灵敏度，不强行开放未上报设置。固件 OTA、官方云端 AI 翻译与语音包安装使用官方 App。

完成 60 项离线测试、7 项 WPF 交互与退出回归、33 张原生预览和隔离单 EXE 启动检查。新增功能尚未实机写入验收。完整协议、型号覆盖与边界见 `feature-coverage-0.3.0.md`，实际收据见本目录 JSON。
