# 漫步者耳机助手

> **下载**：[Windows 便携版与源码包](https://github.com/HappyAny/edifier-manager/releases/latest) · **许可**：GPL-3.0-only；第三方组件保留各自许可。

W820NB、W820NB 双金标版、W830NB 与 Lolli ANC 的独立 Windows 管理工具。原生 WPF，沿用 PILL 的紧凑卡片、浅色 / 深色 / 系统主题，使用青绿色强调色。

**当前版本 0.3.0。补齐已核对协议且可独立实现的本地控制；新增功能通过离线协议与原生界面测试，尚未完成真实耳机写入验收。**

## 运行

打开 `dist/standalone/Edifier.exe`。这是 Windows x64 单文件程序，含图标与 .NET 10.0.14，无需另装 Python、Node 或 .NET。首次启动会把 WPF 原生组件解压到当前用户临时目录。支持 Windows 10 2004 及以上版本。

交付包 `dist/Edifier-Desktop-0.3.0-win-x64.zip` 包含 EXE、源码 ZIP、文档、第三方许可证和 SHA-256 清单。已安装副本位于 `%USER_TOOL_DIRECTORY%\tools\Edifier.exe`，可通过喵喵小工具启动。

先在 Windows 配对耳机，再在工具中扫描、连接。手机上的 EDIFIER Connect 可能占用管理连接，连接失败时可先关闭手机 App。

## 已实现的功能

| 功能 | 行为 |
|---|---|
| 电量、固件与音频 | 区分头戴、左右耳与充电盒电量；不把未知电量当作零；调整所选耳机的 Windows 音量和静音 |
| 降噪与环境声 | 按固件返回的类型选择模式、调整环境声强度；切换后允许状态短暂滞后，只重读、不重复写入 |
| EQ 预设 | 增加 Lolli ANC 的类型 50：经典、重低音、清澈人声、高音增强、剧院 |
| 自定义 EQ | 支持已核对的 1–18 类型布局；根据类型开放增益、频率与 Q；逐段验证、恢复默认、JSON 导入预览与导出 |
| Lolli ANC 触控 | 类型 30 的左右耳双击、三击、长按；无功能、播放暂停、上下曲、降噪循环、游戏模式、音量、语音助手；循环选择两至三种模式 |
| 提示音 | 旧版音量 / 开关与新版分项提示音、音量；保留耳机返回的协议类型 |
| 游戏与佩戴检测 | 低延迟开关；摘下暂停、戴回播放等固件支持的选项 |
| 灵敏度、风噪与节电 | 在耳机明确上报且可成功读取时开放触控灵敏度、防风噪、无音频自动关机 |
| 双设备 | 可配置固件提供开关；Lolli ANC 1.0.9 未上报独立开关时提供官方 A→B→A 配对指引 |
| 名称与定时 | UTF-8 名称长度检查，改名后按设备身份继续识别；定时关机与取消倒计时 |
| LDAC | 关闭、48 kHz、96 kHz；独立确认操作，无法读回时标为待重连确认 |
| 寻找耳机 | 向选定耳机音频端点播放 8 秒提示音，支持左右通道和停止；不改系统音量、不回退到默认扬声器 |
| 设备管理 | 按能力开放断开音频、进入配对、关机、清除配对、恢复出厂；执行前有明确确认，未收到应答不算完成 |
| 备份与诊断 | 修改前自动备份、导入预览、同设备恢复；提供功能状态、诊断导出、对应型号官方说明书入口 |

功能表描述的是软件实现范围，不代表每款耳机拥有全部硬件能力。界面同时检查能力位、已识别的格式与成功读取的状态。只有触控方式标志不代表支持调整灵敏度。未知类型不会猜测写入。

W820NB 与双金标版保持头戴界面；W830NB 不套用双金标版的按键配置；Lolli ANC 提供双耳、声音、触控、设置四页。Plus、三金标、空间音频版及 Lolli 后续型号不作为同一产品开放写入。

## 双设备与连接中断

Lolli ANC 官方流程：先连接 A，再在 B 搜索并连接，最后回到 A 手动连接耳机。必要时双耳入盒并开盖，长按盒上按键约 3 秒进入配对。再次开机会回连最后两个设备。软件没有获得两台音频设备的独立在线名单，因此不显示虚假的“两台均已连接”。

有独立开关时，先备份再写入，TWS 需左右耳在线。双设备设置在恢复批次最后执行；耳机重启、丢失应答或无法读回时，显示待重连校验。不会自动重发。LDAC 同样使用独立流程。

## 备份与数据

- 自动备份：`%LOCALAPPDATA%\EdifierManager\backups`；预览备份在 `preview-backups`。
- 导入核对设备摘要、型号、固件、协议、能力及功能格式。恢复持久设置与自定义 EQ，不重启旧倒计时，不恢复名称；LDAC 请单独修改。
- 修改一批设置时，先校验全部参数，再备份；读回失败停止后续写入。前面已经成功的设置不会自动撤销。
- `known-headsets.json` 保存设备地址摘要与已验证型号，用于改名后的发现；不保存明文地址。
- 诊断包含功能状态和相关命令数据，不会自动上传。查找提示音需要真实音频连接；关机、超出范围或单声道输出会限制寻找效果。

## 离线预览

右上角菜单可选择三款耳机预览。预览支持示例设置与备份，不扫描蓝牙、不播放音频、不修改真实耳机。Lolli 的能力组合来自已读取的 1.0.9 记录；新增设置值是模拟数据，W830NB 的类型组合也只是示例。

固件刷写、官方云端 AI 翻译、语音包下载 / 安装不在本地实现范围；界面提供官方 App 入口。缺少独立控制协议或未识别的返回格式会明确显示状态。详见 [功能覆盖与边界](docs/feature-coverage-0.3.0.md)。

## 构建与验证

需要 .NET 10 SDK 和 Python 3。构建脚本可用 `--offline-feed <NuGet 包目录>`。

```powershell
dotnet run --project tests/EdifierManager.Tests.csproj -c Release
dotnet run --project tests/WindowLifecycle/WindowLifecycle.Tests.csproj -c Release
python tools/build_portable.py
python tools/verify_portable.py
python tools/package.py
```

`verify_portable.py` 使用 `pefile` 与 `Pillow`。当前收据在 `docs/offline-tests.json`、`docs/window-close-tests.json`、`docs/portable-build-0.3.0.json`、`docs/portable-check-0.3.0.json`；界面截图在 `docs/ui`。命令行 `--preview --lolli` 或 `--preview --w830` 可直接进入预览。
